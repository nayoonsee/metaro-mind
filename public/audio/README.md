# 오프닝 시퀀스 효과음

`fortune.html`의 신당 입장 시퀀스가 아래 3개 파일을 재생하도록 연동되어 있고,
실제 음원 파일이 이 폴더에 적용되어 있습니다 (제3자 샘플 없이 절차적 합성으로 제작).

- `shrine-bell.mp3` (1.78초) — 입장 버튼 클릭 시 1회 재생 (볼륨 0.22)
- `shrine-wind.mp3` (8.05초, 반복) — 닫힌 문이 나타날 때부터 반복 재생 (볼륨 0.10, 질문 입력 화면 진입 직전 1초간 페이드아웃)
- `shrine-door-creak.mp3` (3.19초) — 닫힌 문에서 열린 문으로 전환될 때 1회 재생 (볼륨 0.24)

볼륨 값은 `fortune.html`의 `OP_AUDIO_VOL` 상수와 동일하게 유지해야 합니다.
파일이 없어도 조용히 무시되고(에러 없이) 화면 전환은 정상 진행되는 구조는 그대로입니다.
