# 오프닝 시퀀스 효과음

`fortune.html`의 신당 입장 시퀀스가 아래 3개 파일을 재생하도록 이미 연동되어 있습니다.
파일이 없으면 조용히 무시되고(에러 없이) 화면 전환은 정상 진행됩니다.
이 폴더에 아래 파일명 그대로 넣으면 즉시 재생됩니다.

- `shrine-bell.mp3` — 입장 버튼 클릭 시 1회 재생 (권장 볼륨 0.32, 짧고 낮은 방울 소리)
- `shrine-wind.mp3` — 닫힌 문이 나타날 때부터 반복 재생 (권장 볼륨 0.12, 질문 입력 화면 진입 직전 1초간 페이드아웃)
- `shrine-door-creak.mp3` — 닫힌 문에서 열린 문으로 전환될 때 1회 재생 (권장 볼륨 0.42, 길이 2.3~2.7초, 낡은 나무문이 천천히 열리는 낮고 자연스러운 소리)

비명, 귀신 소리, 천둥, 갑작스러운 충격음은 사용하지 않는 것을 권장합니다.
