# 표시 방식 보완 — 기본 브랜드 상태 · 인사말 예시 · 고객용/상담자 검토 분리

1. **기본 브랜드 상태**: 디자인 화면에 "저장된 기본 브랜드" 칸을 두어 저장된 브랜드명·디자인·로고·인사말·마지막 안내문 여부를 보여 줘요(없으면 "없음"). 새 고객 자동 적용은 그대로예요.
2. **인사말 예시 4개**: 누를 때만 인사말 칸에 들어가고, 넣은 뒤 자유롭게 고칠 수 있어요. 누르기 전에는 쓴 문장을 바꾸지 않아요.
3. **고객용 리포트**: 부록 제목은 "나의 명식", 명식표·오행표는 그대로예요. 단락별 "근거" 각주와 계산 요소·계산 기준은 고객용에서 숨겨요. 실제 해당하는 한계(출생 시간 모름·절기 경계·옛 표준시/서머타임·서머타임 경계·밤 11시대)와 "미래를 확정하는 자료가 아니에요" 안내는 짧게 남겨요. 숨긴 근거·부록을 가리키던 생성 안내 문장은 편집하지 않은 경우에만 표시 때 바꿔요.
4. **상담자 검토**: 확인·PDF 화면의 "상담자 검토 보기"와 "상담자 검토 내보내기(HTML)"에서 근거 각주·계산 기준(편집 포함)을 모두 볼 수 있어요.
5. **데이터 보존**: 표시 방식만 바꿨어요. 생성 데이터·동결된 v1~v3 생성기·문단 ID·편집은 그대로이고 자동 재생성하지 않아요. 생성기 버전은 올리지 않았어요(v4 유지).
6. **검토 다시 확인**: 고객용 렌더러 revision(customer-2)을 검토 hash에 넣어, 이전 검토 완료는 한 번 더 체크해야 해요. 미리보기·인쇄·PDF는 같은 고객용 렌더링이에요.
