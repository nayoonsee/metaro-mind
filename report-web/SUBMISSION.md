## 2. C 돈 고민: 하나의 순서
- 순서를 하나로 정리했어요: 1단계 고정 지출·결제 목록 확인 → 2단계 실제 잔액·필수 지출 확인 후 저축 가능액 결정 → 3단계 그다음 자동이체. 입력한 사실("고정 지출 미정리")을 1단계에 반영했고, 기간 계획(1·2·3개월)도 같은 순서로 맞췄어요.
- 비겁 위치는 "사주로 지금의 소비 내역을 알 수는 없어요. 실제 기록에서 모임비·선물·대신 낸 돈이 크게 나오면 4장을 다시 보세요"라는 조건부 안내로 바꿨어요.
- 겹치던 문단을 없앴어요: 사람 지출 첫 순서, 저축 첫 실행, 2개월 차 자동이체 계획, 들어오는 돈/새는 돈 문단.
