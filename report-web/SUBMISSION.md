## 미검증 범위
- **Windows Edge·Chrome, Mac Chrome·Safari, 모바일 브라우저는 실행하지 않았어요.** 지원 검증 완료가 아니에요.
- 실제 인쇄 대화상자에서 사람이 "PDF로 저장"을 눌러 만든 파일은 확인하지 않았어요. 같은 인쇄 문서를 Chromium 인쇄 엔진(page.pdf)으로 저장해 확인했어요. 대화상자의 "배경 그래픽" 옵션이 꺼져 있으면 표지 색이 빠질 수 있어서 화면과 시작 안내에 켜도록 적었어요.
- 브라우저 버전에는 서버의 자동 페이지 나눔 검사(Poppler)가 없어요. 짧은 끝 페이지 등은 저장한 PDF를 직접 보고 확인해야 해요. 로컬 버전의 밀도 자동 조정도 없어요(기본 밀도로 인쇄).
- 실제 HTTPS 호스팅에 올려 보지 않았어요(공개 배포 금지). 로컬 http://127.0.0.1(브라우저가 보안 출처로 취급)에서만 시험했어요.
- 이 환경의 headless Chromium은 한글 다운로드 이름을 `download`로 보고해요. 그래서 앱이 지정한 이름을 기록해 확인했어요. 실제 브라우저의 한글 파일명 저장은 직접 확인이 필요해요.
- 명리 전문가 검수, 실제 이메일 연결, 구매자 전용 접근·사용 기간·지원 기간 결정은 남아 있어요.
