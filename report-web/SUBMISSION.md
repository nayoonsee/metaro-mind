# 최종 보완 — 로고 비동기 소유권 · 생년월일 한 칸 · 점수 임계값 결론 제거

1. **로고 업로드 소유권**: 이미지를 디코딩하기 전에 요청 당시 프로젝트(id·전환 세대)를 기억해요. 디코딩이 끝났을 때 다른 고객으로 바뀌어 있으면 결과를 버리고 그 사실을 알려요. 로고는 브라우저 안에서만 처리하고 외부로 보내지 않아요(네트워크 시험: 외부 요청 0).
   - 시험: A에서 업로드 → 디코딩을 1.5초 늦춤 → B로 전환 → 완료 후에도 B 로고는 그대로이고, A 저장본에도 몰래 들어가지 않아요.
2. **생년월일 한 칸**: 기본 화면에는 "생년월일" 한 칸만 보여요. 연·월·일 칸은 접힌 "따로 입력하기(대체 입력)" 안에 두었고, 서로 동기화돼요. 다 입력하지 않은 동안에는 숨은 값도 비워 두어, 화면과 다른 날짜로 만들어지지 않아요.
   - 함께 고친 실제 오류: 열기·가져오기 때 생년월일 칸이 이전 고객 값(빈 칸)으로 표시되던 순서 문제.
   - 시험: 실제 f3f6416 프로젝트를 가져오기 → 저장 → 새로고침 → 다시 열기 해도 날짜가 그대로이고, 입력 변경(stale)으로 처리되지 않아요.
3. **점수 임계값 결론 제거**: "1~5점에서 3점 이하이면 남는 이유가 환경보다 익숙함" 같은 문장을 없앴어요. 3장 "오래 버틸 환경"·7장 "남는 쪽"·8장·기간 계획의 점수 표현을, 실제 역할·권한·배울 조건을 확인하는 질문으로 바꿨어요.
   - 버전 보존 원칙을 지켰어요. 2da4d2e 생성기를 v3로 그대로 고정했고, 새 문장은 새 풀이(v4)에만 들어가요.
   - 실제 2da4d2e 프로젝트(v3)의 3장·7장·8장 편집은 가져오기·인쇄에서 그대로 남아요. v4로의 적용은 기존처럼 "새 풀이로 다시 만들기"와 "이전 풀이로 되돌리기"로만 해요.
