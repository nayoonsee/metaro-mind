사주 리포트 제작 — 시작 안내

설치할 것은 없어요. 프로그램을 배포한 뒤 제공받은 주소(https://로 시작)를 크롬(Chrome)이나 엣지(Edge)로 열면 바로 쓸 수 있어요. 주소는 아직 정해지지 않았고, 정해지면 따로 안내해요. 프로그램 설치, 명령어, API 키, 유료 AI 계정은 필요 없어요.

1. 리포트 만들기

  1. 입력: 브랜드명·대표 색·표지, 고객 이름, 생년월일(양력/음력·윤달), 태어난 시간(모르면 "시간 모름"). 고민은 선택이에요.
  2. 리포트 생성을 누르면 이 브라우저 안에서 바로 계산하고 풀이를 만들어요. 고객 정보는 다른 곳으로 보내지 않아요.
  3. 내용 확인·수정: 문장을 직접 고칠 수 있어요. 자동 풀이 범위 밖 고민이면 7장에 직접 써야 최종본이 돼요.
  4. 전달 탭에서 "검토 완료"를 체크해요. 내용·브랜드·고객 정보를 바꾸면 검토가 자동으로 풀려요.
  5. 미리보기·PDF 탭 → PDF로 저장(인쇄 창) → 대상 "PDF로 저장", 용지 A4, 배경 그래픽 켜기 → 저장.
브랜드 설정 + 검토 완료 + (필요하면) 직접 작성이 모두 갖춰져야 최종본이에요. 아니면 매 쪽에 "검토용 · 최종본 아님"이 찍혀요. 저장한 PDF는 고객에게 보내기 전에 한 번 끝까지 넘겨 보세요.

2. 저장과 백업 (꼭 읽어 주세요)

  • 작업은 이 브라우저에만 저장돼요. 브라우저 데이터(쿠키·사이트 데이터)를 지우거나, 다른 컴퓨터·브라우저로 바꾸면 보이지 않아요.
  • 작업이 끝나면 오른쪽 위 JSON 백업으로 파일을 받아 두세요. 다시 쓸 때는 JSON 불러오기로 복원해요.
  • 저장 공간이 부족해 저장에 실패하면 화면이 다른 프로젝트로 넘어가지 않아요. 그때는 바로 JSON 백업을 받아 두세요.

3. 아직 준비 중인 것

  • 자동 이메일 발송: 연결 준비 중이에요. 지금은 저장한 PDF를 직접 메일에 첨부해 보내 주세요.
  • 리포트 문장은 명리 전문가 검수 전 초안이에요. 고객에게 보내기 전에 꼭 읽고 고쳐 주세요.

4. 알아 두기

  • 지원 범위: 1900~2099년, 한국 출생(한국 표준시, 서머타임 자동 보정). 밤 11시대 출생은 검토 항목으로 표시돼요.
  • 확인한 환경: 리눅스의 Chromium. Windows의 엣지·크롬, Mac의 크롬·사파리에서는 아직 직접 확인하지 않았어요. 인쇄 결과가 다르면 알려 주세요.
  • 이 주소를 계속 쓸 수 있는 기간, 구매자 전용 접속, 지원 기간은 아직 정해지지 않았어요. 정해지면 따로 안내해요.

리포트는 성향을 이해하고 선택을 점검하는 참고 자료예요. 미래를 확정하거나 의료·법률·투자 판단을 대신하지 않아요.
