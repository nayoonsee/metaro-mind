# 상담자 검토 항목 (고객에게 보내지 않음) · 가상 사례 B

- [ ] (R-job) 직업·하는 일을 입력받지 않았어요. "일" 항목에 실제 업무 맥락을 넣을지 상담 후 결정하세요. 없으면 지금 문장 그대로 둡니다.
- [ ] (R-relation) 연애·가족 등 관계 상황을 입력받지 않았어요. 특정 상대나 궁합 내용은 쓰지 않았어요.
- [ ] (R-experience) 실제 경험 사례가 없어요. 각 항목에 내담자 사례 1개씩 넣으면 개인 맞춤도가 올라가요(상담자가 직접 작성).
- [ ] (R-strength) 강약(신강·신약) 판단은 하지 않았어요. 필요하면 상담자가 쓰는 관법 기준을 밝히고 직접 추가하세요.
- [ ] (R-notice-clock) 계산 안내: 태어난 때 한국 시계는 지금과 기준이 달라서, 오늘날 한국 표준시로 -60분 바꿔서 계산했어.
